## Исправления и проверяемые результаты

- Popup обновляет статус раз в секунду, пока открыт и видим. Запоздалый ответ не перезаписывает состояние Off. Модульные регрессии проверяют Working → Done → Idle без изменения настроек, гонку с выключением и остановку таймера при закрытии.
- Body/head MutationObserver отключаются при Off; флаги активности/непрочитанности очищаются. При включении текущая генерация определяется заново. Тест проверяет отсутствие сканирований при изменениях страницы и focus во время Off.
- Видимость проверяется только для подходящих Stop-кнопок; известные testid проверяются первыми. Мутации потокового текста и подсветки за пределами кнопок не вызывают сканирование. Сценарий с 2500 Copy-кнопками проверяет отсутствие чтений layout для них и отсутствие повторных сканирований от 2500 изменений текста и 2500 изменений class.
- Смена pathname очищает состояние и отложенное завершение предыдущего чата; popstate обрабатывается отдельно. Проверки включают навигацию во время 500 мс задержки, замену body, русские и английские Stop, ручную остановку, возврат фокуса и независимые вкладки.
- Сохранены передача состояния при повторной инъекции/обновлении, защита от дубликатов, точное восстановление атрибутов favicon, обработка замены favicon сайтом, цвета Working/Done и сброс настроек.
- Собственные PNG 16/32/48/128 подключены и как icons, и как action.default_icon; логотип магазина — 300×300. Manifest, package.json и BUILD согласованы на 1.2.2. Упаковщик отвергает расхождения версий, update_url, отсутствующие ресурсы и неверные размеры PNG.

## Живой ChatGPT и снимки

**Подтверждено владельцем 28.10.2026.** После предложенного ручного прогона владелец сообщил «все работает» и отдельно отметил, что точка работает хорошо. Это пользовательское подтверждение живого сайта; инструмент не проводил собственную автоматизированную живую проверку. Далее запрошены только скругление меню, тёмная окантовка и увеличение точки.

**История инструментальной диагностики:** настоящий `https://chatgpt.com/` в чистом Edge показал Cloudflare «Подтвердите, что вы человек». Интерфейс чата и текущие Stop-контролы недоступны. После challenge необходимость входа не установлена. Обход проверки не предпринимался. Компьютерное управление окнами недоступно (native pipe не найден); запасной инструмент не обнаружил подключённых браузеров.

`artifacts/browser-live-report.json` и `artifacts/live-chatgpt-access.png` — диагностические материалы, исключённые из Git и ZIP. Тест доступности не утверждает успешной генерации. Снимки живого ChatGPT не получены. Для карточки позже подготовлены снимок настоящего popup из офлайн-сценария и явно подписанные иллюстрации вкладок; их нельзя выдавать за снимки живого сайта. Методика ручной проверки: [live-check.md](live-check.md). Автоматизированного живого прогона нет; последующая ручная проверка подтверждена владельцем, как указано выше. Скриншоты в документации Microsoft помечены как Optional; их отсутствие не является самостоятельным препятствием к подаче.

## Публичная политика и сеть

Расширенная PRIVACY.md опубликована на GitHub main коммитом `155daa1c428f8c547ab6d7f2efa8aaffb0250cd8`. Повторное чтение через GitHub подтвердило точное совпадение с политикой в отправленном ZIP 1.2.2. SHA-256 этих байтов: `5d4fa835ab3d0b3146c2caa3d42231823cb72bad5e2ec152d4832d4a76c1116c`. Прежний HTTP 200 относился к старой редакции; новая редакция проверена через GitHub, без отдельного утверждения о повторном HTTP-прогоне.

Подтверждены code-level ограничения fetch: только три host, публичные favicon-пути, отсутствие credentials/referrer и redirects, лимит ответа, контроль MIME, отказ при ошибках. Приватные URL/API отклоняются до сетевого обращения. Дополнительная сетевая проверка в Edge подтверждает отсутствие Cookie/Referer при построении реального запроса. Остальные синтетические страницы используют встроенные изображения; это не проверка всей сети живого ChatGPT. IP и обычные сетевые метаданные доступны настоящему серверу при реальной загрузке favicon, что раскрыто в политике и материалах Privacy.
